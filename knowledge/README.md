# Knowledge Tree — Mirror Consumer

Mirror-DataNest contributes observable repository evidence to the canonical DataNest Knowledge tree and consumes only the feed addressed to Mirror R&D.

- Mirror does not certify repository learning.
- The consumer accepts only `datanest-knowledge-feed-v1` with target `mirror`.
- Feed content must remain provisional, non-certified, and non-authorizing.
- The local inbox lives on the isolated `automation/knowledge-inbox` branch instead of Mirror `main`.
- FREETREE is excluded from ingestion and synchronization.
